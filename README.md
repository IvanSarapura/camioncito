# Camioncito

MVP de trazabilidad para camiones de recolección urbana. Incluye un tablero operativo con flota, recorridos, incidencias y sugerencias de ruta de demostración.

## Empezar

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000).

## Comandos útiles

```bash
npm run lint
npm run typecheck
npm test
npm run build
```
